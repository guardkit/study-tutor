# Task: Split TASK-NATS-PH1-006 into its own wave (defensive, optional)

## Description

**This is an optional belt-and-braces fix.** TASK-NATS-FIX-001 is the load-bearing change
that unblocks the FEAT-39E1 re-run. This task adds a second line of defence: move
TASK-NATS-PH1-006 out of the parallel Wave 2 group `[002, 003, 006, 007]` into its own
serial wave 2b, so the orchestrator's `_detect_source_file_contention` logic — which
[TASK-REV-CC40](../../../.claude/reviews/TASK-REV-CC40-review-report.md) found has
false-positive behaviour in shared-worktree mode — cannot fire against TASK-006 at all.

**Apply this only if FIX-001 alone feels risky for the demo deadline (2026-05-11).** The
cost is ~3 minutes of additional serial wall-time; the benefit is removing one whole risk
surface for the run.

The upstream GuardKit fix
([TASK-FIX-CC-COND](/Users/richardwoollcott/Projects/appmilla_github/guardkit/tasks/backlog/TASK-FIX-CC-COND-source-file-contention-false-positives.md))
will remove the need for this kind of defensive wave-splitting once the false-positive in
`_detect_source_file_contention` is fixed.

## Scope

Single edit: `.guardkit/features/FEAT-39E1.yaml`, `orchestration.parallel_groups` block
(lines ~306–326).

**Current layout (line 306+):**
```yaml
orchestration:
  parallel_groups:
  - - TASK-NATS-PH1-001
  - - TASK-NATS-PH1-002
    - TASK-NATS-PH1-003
    - TASK-NATS-PH1-006   # <- problematic peer-overlap target
    - TASK-NATS-PH1-007
  - - TASK-NATS-PH1-004
  - - TASK-NATS-PH1-005
  - - TASK-NATS-PH1-008
  …
```

**New layout:**
```yaml
orchestration:
  parallel_groups:
  - - TASK-NATS-PH1-001
  - - TASK-NATS-PH1-002    # wave 2a (parallel) — peers don't overlap with each other
    - TASK-NATS-PH1-003
    - TASK-NATS-PH1-007
  - - TASK-NATS-PH1-006    # wave 2b (serial) — runs after 002/003/007 complete
  - - TASK-NATS-PH1-004
  - - TASK-NATS-PH1-005
  - - TASK-NATS-PH1-008
  …
```

`TASK-NATS-PH1-006` keeps `dependencies: [TASK-NATS-PH1-001]` (already correct — it does
not depend on 002/003/007 in code, but running them first eliminates their files from the
worktree-diff noise that confuses the contention detector).
